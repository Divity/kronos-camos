Kronos Camo Slots

Every camo in the game and which texture sits in each of its 36 slots. Find the camo you want to replace, then drop your PNGs in the folder shown.

1. Find a camoSearch by name, or filter by game and mode. Zombies camos have zm in the name.
2. Make the folderkronos\Assets\Camos\<your pack>\<camo name>\
3. Add PNGs by slotName each file after its slot number, like 0.png or 7.png. Only slots that camo already uses do anything.
